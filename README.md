# quote-generator

A command-line program that prints one randomly chosen inspirational quote.
It uses only Python's standard library (`random`) and contains ten
original sample quotes labeled "Unknown" rather than attributing them to real people.
Quotes may repeat between runs; random selection does not guarantee a new quote.



Install Python 3.8 or newer with venv and pip available.
The completed teammate test used Python 3.12.8 on Linux.
No third-party packages or network access are required.

#Setup and run: macOS / Linux

Open a terminal in the parent folder of the extracted project:


cd quote-generator
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py


Setup and run: Windows PowerShell

powershell
cd quote-generator
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python main.py


If local policy prevents PowerShell activation, use Command Prompt with
.venv\Scripts\activate.bat, or invoke .venv\Scripts\python.exe` directly.

#Dependency snapshot

The initial environment was created and activated, then the following command
was actually run to create the included requirements file:


python -m pip freeze > requirements.txt


requirements.txt is intentionally empty: the project has no third-party
dependencies. Built-in modules such as `random` are not pip packages and must
not be added to this file. The Python interpreter itself must be installed
separately; requirements.txt does not pin or install it.

#Teammate test: macOS / Linux

Starting with an activated project environment:


deactivate
rm -rf .venv
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --no-index -r requirements.txt
python -m pip check
python main.py
deactivate


#Teammate test: Windows PowerShell

powershell
deactivate
Remove-Item -Recurse -Force .venv
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --no-index -r requirements.txt
python -m pip check
python main.py
deactivate


The Linux test above was actually performed successfully. The original virtual
environment was deactivated and deleted, a fresh one was created and activated,
and dependencies were installed using only requirements.txt with index access
disabled. The program then ran successfully. A further validation checked the
quote list structure and verified 25 outputs against the available quotes.
See teammate-test.txt for the captured execution output. Windows instructions
are provided for reproducibility but were not executed in this environment.

Files

main.py: quote data and executable entry point.
requirements.txt: empty dependency snapshot generated by pip freeze.
.gitignore: excludes virtual environments, caches, builds, and local files.
README.md: setup and reproduction instructions.
teammate-test.txt: actual successful test output.

The virtual environment is deliberately not distributed: recreate it locally
using the instructions above. Random quote output is intentionally variable;
the setup and execution procedure are reproducible.
